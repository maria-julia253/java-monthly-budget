# java-monthly-budget

> About the Project: 

  Java program that calculates a user's monthly budget based on their total income and expenses.

> Featured technologies:

1. Java;
2. Arrays;
3. Scanner;
4. Conditional Structures;
5. Repetition Structures.

> Features:

1. Registering the amount of income sources;
2. Registering the amount of expenses;
3. Calculating the amount of income sources;
4. Calculating the amount of expenses;
5. Identifying the budget situation:
		A) Positive budget;
		B) Negative Budget;
		C) Balanced budget.

> Calculation rules:

> Educational goal:

   Training of conditional and repetition structures in Java.
